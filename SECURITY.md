# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or leaked credential in any repository under `github.com/lopes`, please report it privately via [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the affected repository rather than opening a public issue.

Please include:
- The repository and commit SHA or file path affected.
- Steps to reproduce or verify the issue.
- Potential impact assessment.

Reports are reviewed promptly and remediated before public disclosure.
